# PRISM

PRISM provides simulation-based model selection and parameter inference for
diffusion MRI and additive symbolic models.

Start with [installation and quickstart](getting-started.md), or work through
the [symbolic quickstart notebook](examples/index.md).

## Guides

- [Training](guides/training.md): datasets, optimization, tracking, checkpoints,
  and resume.
- [Symbolic regression](guides/symbolic.md): observation formats, posterior
  sampling, and custom expressions and priors.
- [dMRI prediction](guides/prediction.md): input data, pretrained models, and
  exported maps.
- [Evaluation](guides/evaluation.md): sampling, metrics, and export configuration.
- [Simulators](guides/simulators.md): compartments, acquisitions, priors, and noise.

## Reference and experiments

- [Reference](reference/index.md): CLI options, configuration keys, and Python API.
- [Experiment presets](reference/experiments.md): model and training settings.
- [Run the experiments](https://github.com/mackelab/prism#run-the-experiments):
  one train and one evaluate command for each main experiment.
- [Paper workflows](paper_experiments.md): figure recipes, protocol pages for
  Figures 4b, 4c, 6b and 6c, checkpoint requirements, and available source results.
- [Development](development.md): tests and documentation builds.
